# Game shop role icons

`itemshop_texture_atlas.png` is the original Riot Games item-shop atlas, retrieved
2026-09-25 from CommunityDragon:
https://raw.communitydragon.org/latest/game/assets/ux/itemshop/itemshop_texture_atlas.png

The board uses CSS sprite windows, retaining the original image unchanged.
Source pixel windows (x, y, width, height):

- Tank: 868, 110, 30, 30
- Fighter: 868, 26, 30, 30
- Assassin: 938, 200, 30, 30
- Mage / AP: 868, 56, 30, 30
- Marksman / AD: 868, 82, 30, 30
- Support: 840, 211, 30, 30

Displayed at 80% scale. A theme token darkens the gold in light mode.
Artwork belongs to Riot Games; CommunityDragon is the extraction/distribution source.
