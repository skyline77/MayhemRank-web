# 海斗榜 · 前端

英雄联盟「海克斯大乱斗」的胜率与出装统计网站：<https://haidoubang.com>

本仓库是网站的前端（Vue 3 + TypeScript + Vite），支持简体、繁体、日文、英文。统计数据由独立的后端按快照生成，不包含在本仓库中。

## 性能优化

以下数字均为改前、改后对比，在本机无头 Chrome 中测量：加载与渲染类开启 4 倍 CPU 降速，取 3 轮中位数；动画类为逐帧记录。每次改动都用 45 个页面场景的 DOM、布局和滚动快照确认显示结果不变。

### 加载与渲染

| 优化                     | 做法                                                                                                 | 效果                                              | 提交      |
| ------------------------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------- | --------- |
| 复用格式化器、合并测量   | 按语言缓存 `Intl.NumberFormat`；组件更新后的布局测量合并到下一帧，避免数据分批到达时反复强制整页布局 | 再次展开详情累计阻塞 345→27ms，切换英雄 326→255ms | `fab4e48` |
| 按行分步渲染、按下即预取 | 详情先渲染等高占位，每帧换出一行真实卡片；鼠标在头像上按下时预取数据                                 | 首次展开最长停顿 337→254ms，卡片出现 1720→1452ms  | `e5185b8` |
| 屏外的行延迟生成         | 用 IntersectionObserver，只有视口附近的行才生成卡片                                                  | 首次展开最长停顿 383→296ms                        | `cf2c675` |
| 减少组件层级             | 卡片组件内联外框、链接、差值三个子组件，每张卡只建一个组件实例，DOM 不变                             | 切换到 211 张卡片的榜单，最长停顿 495→410ms       | `c70efee` |
| 非必需数据延后读取       | “近期改动”在浏览器空闲时读取，不与首屏图标争用连接                                                   | 同时试过延后组合数据，实测晚到约 1.8s，已撤回     | `6c582b5` |
| 筛选数据打包             | 每个英雄的筛选数据合并为 gzip 包，用 `DecompressionStream` 解压，切换同类条件不再请求                | 服务端文件 2.4GB→0.37GB                           | `eb3675d` |

### 动画流畅度

详情面板展开、收起时，表格要整体重排，同时页面要跟随滚动。

| 优化                       | 做法                                                                                                                                        | 效果                                                              | 提交                |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------- |
| 消除动画期间的强制样式重算 | 滚动监听中的布局读取推迟到动画结束；高频写入的 CSS 自定义属性用 `@property` 注册为不继承                                                    | 原先每次写入都要重算约 1300 个元素，现在收起期间主线程每帧 8–11ms | `6061023`           |
| 限制长帧造成的跳变         | 展开时动画时钟每帧最多前进 17ms，挂载内容的长帧不再让高度一帧跳过大半                                                                       | —                                                                 | `6061023`           |
| 卸载移出动画帧             | 先画出高度为 0 的最后一帧，再在下一个任务卸载详情                                                                                           | 最长帧间隔 37–42ms→29ms                                           | `c742aa5`           |
| 动画期间只显示占位         | 展开过程中只渲染占位卡片，落位后再分帧填充内容                                                                                              | 超过 20ms 的帧减少到 2–3 个                                       | `6fae63a`           |
| 消除布局跳变               | 用 Web Animations API 为区间标签的拆分与合并做位移动画；行间距收回直接操作 DOM 类名，由 CSS 过渡与 JS 补间同步，避开整表重新渲染（约 12ms） | 收起过程连续，无突变                                              | `c1b81dd` `c3c1eba` |
| 收起曲线                   | 320ms ease-out quint，剩余高度不足 0.5px 即结束，避免末段停顿                                                                               | 合上前逐帧减速                                                    | `aa2f034`           |

## 开发

需要 Node 22 与 pnpm。

```sh
pnpm install --frozen-lockfile
pnpm dev          # 开发服务；数据接口代理到本机 127.0.0.1:18767 的后端
pnpm test         # Node 内置测试
pnpm lint
pnpm format:check
pnpm build        # vue-tsc 类型检查后构建
```

本仓库不含后端，`pnpm dev` 打开的页面没有数据，只能查看界面结构。测试与构建可以独立运行。

### 目录

| 目录                            | 职责                                                               |
| ------------------------------- | ------------------------------------------------------------------ |
| `app/`                          | 站内路由、浏览器历史与滚动恢复、全局快捷键                         |
| `i18n/`                         | 界面语言与游戏名称本地化                                           |
| `data/`                         | 版本目录、快照资源与浮窗资料的加载                                 |
| `boards/`                       | 榜单共用：胜率表、条带计算、重排动画；以及英雄榜、海克斯榜、组合榜 |
| `details/`                      | 详情共用：展开与滚动动画、统计行与卡片；以及英雄详情、符文详情     |
| `search/`、`tooltip/`、`stats/` | 搜索、全局浮窗、数值格式与配色                                     |
| `shared/`                       | 与业务无关的通用工具（高度过渡、视口检测等）                       |
| `styles/`                       | 全局样式，导入顺序见 `styles/README.md`                            |
