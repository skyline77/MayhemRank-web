the Wiki's automated-access check at capture time; no challenge was bypassed.

## Chinese Wiki translation (2026-09-25)

`wiki-zh-CN-20260925.json` contains an AI-assisted Simplified Chinese translation
of all 222 captured English excerpts. It is not an official Riot or Wiki
translation, and it does not replace the separate in-game brief descriptions.
The adaptations remain CC BY-SA 3.0, with the original source, contributors and
license retained in the catalogue and displayed in the detail footer.

Each entry retains `sourceDescription` for exact alignment with its English
excerpt. The UI refuses to display a translation against changed English text.
When updating the English capture, update/review the corresponding translation
and run the translation data tests before updating both resource filenames.
Translation loads only on first selecting Wiki翻译 (including a restored cookie
preference), and is cached independently from the English catalogue. No text
is sent to third-party translation services during website use.
