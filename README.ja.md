# 海斗榜（ハイドウバン）· フロントエンド

<https://haidoubang.com>:
League of Legends「ARAM: Mayhem」モードの勝率・ビルド統計サイト

本リポジトリはサイトのフロントエンド（Vue 3 + TypeScript + Vite）です。簡体字・繁体字・日本語・英語に対応しています。統計データは別のバックエンドがスナップショットとして生成しており、本リポジトリには含まれません。

## パフォーマンス改善

以下の数値はすべて改善前後の比較で、ローカル環境のヘッドレス Chrome で計測しました。読み込み・描画は CPU 4 倍スロットリングで 3 回計測した中央値、アニメーションはフレーム単位の記録です。各変更では 45 画面シナリオの DOM・レイアウト・スクロール位置のスナップショットを比較し、表示結果が変わらないことを確認しています。

## 開発

Node 22 と pnpm が必要です。

```sh
pnpm install --frozen-lockfile
pnpm dev          # 開発サーバー。データ API はローカルの 127.0.0.1:18767 のバックエンドにプロキシ
pnpm test         # Node 組み込みのテスト
pnpm lint
pnpm format:check
pnpm build        # vue-tsc で型チェック後にビルド
```

本リポジトリにはバックエンドが含まれないため、`pnpm dev` で開いたページにはデータが表示されず、画面構成のみ確認できます。テストとビルドは単独で実行できます。

### ディレクトリ

| ディレクトリ                    | 役割                                                                                                                 |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `app/`                          | サイト内ルーティング、ブラウザ履歴とスクロール位置の復元、グローバルショートカット                                   |
| `i18n/`                         | UI の言語とゲーム内名称のローカライズ                                                                                |
| `data/`                         | バージョン一覧、スナップショット素材、ツールチップ資料の読み込み                                                     |
| `boards/`                       | ランキング共通部分（勝率表、帯の計算、再配置アニメーション）と、チャンピオン・オーグメント・組み合わせの各ランキング |
| `details/`                      | 詳細共通部分（開閉とスクロールのアニメーション、統計行とカード）と、チャンピオン詳細・オーグメント詳細               |
| `search/`、`tooltip/`、`stats/` | 検索、グローバルツールチップ、数値の書式と配色                                                                       |
| `shared/`                       | 業務に依存しない汎用ツール（高さのトランジション、ビューポート判定など）                                             |
| `styles/`                       | グローバルスタイル。読み込み順は `styles/README.md` を参照                                                           |
